# 修仙小说事实提取改进建议

生成时间: 2025-11-08 14:41:22
评估片段数: 3

=== 发现的问题 ===  
1. 角色关系动因缺位  
   仅记录“王天古等人”与韩立敌对，却未提取结仇事件（夺宝/杀徒/破坏计划），导致关系网络无权重、无法预测后续冲突烈度。  

2. 资源流转链断裂  
   对“玉简”“阴煞血尸”等关键资源，只标记“存在”而忽略来源（抢/买/赠/炼）、当前控制权、交易条件，失去对资源再分配与剧情 stakes 的追踪能力。  

3. 实力体系锚点模糊  
   法术、神通、古宝未与已知体系做“映射”（青元剑盾？新创？上古？），无法量化战力差，也无法判断越阶反杀合理性。  

4. 时空坐标颗粒度不足  
   “荒野之地”“明日最后约定时旬”缺少地理坐标、势力边界、时辰倒计时，导致多条剧情线无法对齐，叙事节奏评估失真。  

5. 事件类型与动机留白  
   只记录“明日见面”却未提取事件性质（交易会/围猎/谈判/秘境开启），所有角色动机与资源投入无法建模。  

6. 状态快照不完整  
   战斗片段未同步记录双方“已祭出/未祭出”法宝、护罩、灵兽，实力对比停留在静态标签，动态博弈链断裂。  

=== 缺失的类型 ===  
1. 关系动因事实（Rel-Motive）  
   定义：记录“某角色对另一角色产生特定态度/立场的触发事件”。  
   示例：  
   - 主体：王天古 → 客体：韩立 → 动因：韩立在落云谷夺其镇宗之宝“虚天残图” → 态度：必杀灭口。  

2. 资源流转事实（Resource-Flow）  
   定义：记录“资源唯一标识 + 获得方式 + 前手 + 后手 + 限制条件”。  
   示例：  
   - 资源：阴煞血尸(ID:RS-018) → 获得方式：白发修士亲手炼制 → 前手：无 → 后手：暂存储物袋 → 限制：需每月以元婴精血喂养。  

3. 体系映射事实（System-Map）  
   定义：将新出现的能力/物品映射到已知修炼体系，并标注“位阶+稀有度+已知克星”。  
   示例：  
   - 物品：青色古灯紫焰 → 映射：上古洪荒火种·排名 37 → 位阶：元婴中期巅峰 → 克星：玄阴真水。  

4. 时空锚点事实（Spatio-Temporal-Anchor）  
   定义：为任何场景或约定提供“可计算”的坐标、倒计时、势力边界。  
   示例：  
   - 地点：荒野之地 → 坐标：慕兰草原以北 1.2 万里，已出“天风榷场”势力圈 → 危险等级：三阶（可能出现 6-7 级妖兽）。  

5. 事件性质事实（Event-Nature）  
   定义：用封闭标签标注事件类型，并给出“资源 stakes+规则+胜利条件”。  
   示例：  
   - 事件：明日辰时会面 → 性质：小型秘市交易会 →  stakes：结丹后期破阶丹主材 → 规则：以物易物，禁飞、禁神识探查 → 胜利条件：换得“寒髓”。  

6. 即时状态快照（Combat-Snapshot）  
   定义：在冲突段落按“回合”粒度记录双方已亮/未亮手段。  
   示例：  
   - 回合 0：韩立 → 已亮：青竹蜂云剑（八口）、辟邪神雷网；未亮：风雷翅、元婴后期傀儡。  

=== 修订后的完整类型定义 ===  
以下 6 大原则 18 子类，任何事实提取必须逐条自检，缺失即视为“覆盖度”扣分。  

原则 1 角色  
1.1 身份：宗门/散修/妖族/古魔 + 职位 + 当前修为  
1.2 关系：对客体的“态度标签”+ Rel-Motive 触发事件  
1.3 立场：在主线矛盾中的阵营（天南/慕兰/第三方/中立）  

原则 2 资源  
2.1 物品：名称、等级、唯一 ID、外形关键特征  
2.2 资源流转：Resource-Flow 五元组（获得方式、前手、后手、限制）  
2.3 功法/神通：体系映射 + 修炼门槛 + 已知破绽  

原则 3 事件  
3.1 事件类型：封闭标签（战斗/交易/谈判/秘境/逃亡/炼制/突破）  
3.2 事件性质：Event-Nature（stakes、规则、胜利条件）  
3.3 时间戳：绝对时辰 + 相对倒计时（用于多线对齐）  

原则 4 地点  
4.1 地理坐标：可换算的里数、方向、势力边界  
4.2 空间属性：禁空/禁神识/灵气浓度/危险等级  
4.3 场景物件：擂台、古阵、残垣等对战斗有影响的要素  

原则 5 实力  
5.1 修为：小境界 + 瓶颈描述  
5.2 手段：已亮/未亮法宝、灵兽、符箓、阵盘（Combat-Snapshot）  
5.3 体系位阶：System-Map 排名、稀有度、克星  

原则 6 规则  
6.1 世界规则：境界压制、飞升限制、天道法则  
6.2 局部规则：秘境禁制、交易会规矩、宗门门规  
6.3 代价与因果：血祭、心魔誓言、天道反噬  

—— 自检口诀 ——  
“角色关系必有因，资源来路要连根；  
事件 stakes 先定性，时空坐标可运算；  
出手一张快照照，体系映射对位阶；  
规则代价写分明，缺一项就扣分。”
